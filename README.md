# PLITAP · Проверки совместимости

Общие проверки соответствия реализаций конкретным версиям спецификации PLITAP.

**Этап:** Опубликована структура направления. Реализация и содержательные материалы будут добавляться отдельными изменениями.

[Карта проекта](https://github.com/Plitap/Plitap/blob/main/REPOSITORIES.md) · [Общие правила участия](https://github.com/Plitap/.github/blob/main/CONTRIBUTING.md)

## Назначение

- Входные примеры и ожидаемые результаты, связанные с требованиями спецификации.
- Сценарии взаимодействия разных реализаций и сетевых условий.
- Инструменты запуска и воспроизводимые отчёты результатов.

## Границы направления

Ожидаемое поведение выводится из [spec](https://github.com/Plitap/spec), а не только из результатов нашего [core](https://github.com/Plitap/core). Внутренние тесты продукта остаются с его кодом. Проверки, отчёты и подтверждённая совместимость пока не опубликованы.

## Структура

| Раздел | Назначение |
|---|---|
| [`vectors/`](vectors/) | Входные данные и ожидаемые результаты с привязкой к версии и пункту спецификации. |
| [`scenarios/`](scenarios/) | Сценарии взаимодействия реализаций, конфликтов и сбоев связи. |
| [`runners/`](runners/) | Инструменты запуска общего набора проверок для разных реализаций. |
| [`reports/`](reports/) | Отчёты с версиями проверяемого кода, условиями запуска и фактическими результатами. |

Каждый раздел сейчас содержит README с его назначением. Названия разделов не обозначают готовую функцию или выбранную технологию.

## Участие

Вопросы об этом направлении и конкретные задачи — в [Issues](https://github.com/Plitap/conformance/issues). Общие идеи — в [обсуждениях PLITAP](https://github.com/Plitap/Plitap/discussions).

Предложение должно объяснять задачу, ожидаемый результат и связанные компоненты. Рабочее обсуждение, принятое правило и опубликованная реализация имеют разные статусы.

## Условия использования

Лицензии для кода, спецификации и визуальных материалов определяются отдельно. См. [статус лицензирования](https://github.com/Plitap/.github/blob/main/LICENSING.md).
